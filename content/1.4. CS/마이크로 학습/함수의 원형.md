#### 배운 것

**원형 선언**은 "이런 함수가 뒤에 있을 거야"라고 미리 알려주는 줄임. 구별 포인트는 **끝이 세미콜론**이고 중괄호 본문이 없다는 것.

![[함수의 원형_잘못된 코드.png|675]]
```c
#include <stdio.h>
int sum(int a, int b);   ← 위 슬라이드에는 없고, 제대로 동작하기 위해 추가해야 하는 줄
int main() {
    int x, y, c;
    scanf("%d %d", &x, &y);
    c = sum(x, y);
    printf("%d\n", c);
}
int sum(int a, int b) {
    int d;
    d = a + b;
    return d;
}
```
